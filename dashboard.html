Methodology

  • Covered Call Action: the dashboard shows the exact call contract to sell to open.
  • Scanned Stock Price: underlying price captured when the report was generated.
  • Live Stock Price: current underlying quote pulled during live overlay generation.
  • Scanned Premium: based on option quote captured at report generation time.
  • Live Overlay: compares current option bid/ask with scanned bid/ask for the same contract.
  • HV Rank: where current 21-day realized volatility sits vs. its 52-week range (higher = better for selling premium).
  • RSI Signal: RSI 45–65 is the sweet spot for covered calls — trending but not overbought.
  • Beta: stocks near beta 1.0 score best; very high or very low beta is penalised.
  • Return on Capital: premium divided by capital required (stock price × 100).
  • Annual Yield: weekly return annualized for comparison only.
Always verify the exact option symbol, strike, and expiration before placing any order.

🔧 Trade logging not yet connected. To enable the trade log, set two environment variables on Render and redeploy: 
SUPABASE_URL=https://<your-project>.supabase.co
SUPABASE_ANON_KEY=<your-anon-key>
Then run this SQL once in your Supabase project to create the trades table: 
create table public.trades (
  id uuid default gen_random_uuid() primary key,
  created_at timestamptz default now(),
  ticker text not null,
  transaction_date date not null,
  stock_price numeric(10,2),
  contracts integer default 1,
  strike numeric(10,2) not null,
  expiration date not null,
  dte integer,
  premium numeric(10,4),
  total_premium numeric(10,2),
  pct_otm numeric(6,4),
  notes text,
  status text default 'open',
  close_date date,
  assignment_price numeric(10,2),
  buyback_price numeric(10,2),
  net_option_pnl numeric(10,2),
  underlying_pnl numeric(10,2),
  total_pnl numeric(10,2)
);
alter table public.trades enable row level security;
create policy "Allow all" on public.trades for all using (true) with check (true);
Until then, P&L stats are read from the published trade_history.json file.
