Methodology

  • Stock Info: summarizes the underlying name, capital needed, trend context, and earnings event risk.
  • Call Setup: shows the practical order ticket you would enter for a single covered-call contract.
  • Scanned Premium: based on the option quote captured when the report was generated.
  • Live Overlay: compares current option bid/ask with the scanned bid/ask to flag stale setups.
  • Suggested Limit: midpoint-based execution hint using current live bid/ask when available.
  • Return on Capital: premium divided by capital required.
  • Delta / Assignment Proxy: rough assignment-likelihood indicators, not guarantees.
  • OTM: percentage distance between current stock price and strike.
  • Annual Yield: weekly return annualized for comparison only.
  • Spread / Volume / Open Interest: liquidity quality inputs.
A recommendation is only useful if it is still executable at decision time. Use the live overlay to avoid acting on stale premiums.
